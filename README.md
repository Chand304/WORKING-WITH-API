# TMDB Movies Data Analysis 🎬

## About This Project

This project uses the TMDB (The Movie Database) API to collect movie information using Python. The collected data is stored and processed using Pandas in a Jupyter Notebook.

## Tools & Technologies

- Python
- Jupyter Notebook
- Pandas
- TMDB API
- VS Code

## Project Features

- Fetch movie data using the TMDB API.
- Collect movie information through API requests.
- Handle multiple pages of API data.
- Convert API responses into a Pandas DataFrame.
- Export movie data into a CSV file.

## Project Files

- `TMDB_Movies.ipynb` — Jupyter Notebook containing the Python code.
- `Movies.csv` — Collected movie dataset.

## How to Run

1. Clone or download this repository.

2. Open the project folder in VS Code.

3. Install the required libraries:

   ```bash
   pip install pandas requests
   ```

4. Add your own TMDB API key securely.

5. Open the Jupyter Notebook.

6. Run all cells to collect movie data.

## Learning Objectives

- Understand how APIs work.
- Learn how to fetch data using Python.
- Practice working with JSON responses.
- Use Pandas for data manipulation.
- Export data into CSV format.
